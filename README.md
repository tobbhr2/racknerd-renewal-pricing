## 锁价的边界：三种情况会让续费同价失效

续费同价只保护“原机器、原套餐、原价格”这个组合。以下几种操作会打破它：

- **升级配置**：开工单补差价升级到常规套餐后，续费价按常规零售价走，原来的特惠价就此失效。升级流程本身很快，按比例补差、重启一次生效，不支持降级。
- **换机房**：不支持保留原价直接迁移，需要新开一台机器迁移数据，再取消原机。
- **套餐过期后重新购买**：如果机器过期太久、数据被清理，只能按当前市价重购。黑五、新年这类节日限时套餐（比如 $10.60/年 的 1GB 款）卖完下架后，那个价格就再也买不回来了——这也是为什么手里的促销套餐只要还用得上，续着比什么都划算。

有长期使用者估算，同等配置的新购价如今普遍比老促销套餐贵三到五成，老套餐的锁价就是实打实的差价。

## 提前续费怎么操作

RackNerd 会在服务到期前 14 天自动生成续费账单并发邮件提醒，但你也可以随时手动提前续，后台两分钟搞定：

1. 登录客户中心（Client Area），进入 Services 服务列表；
2. 点开要续费的那台 VPS；
3. 在左侧 Actions 区域点 **Generate Renewal Invoice**（生成续费账单）；
4. 点账单编号进入支付页，选择支付方式付款，服务周期自动顺延一个完整周期，不会重叠计费。

提前续费不影响锁价，账单仍按你当初的购买价生成。支付方式包括信用卡（VISA/Mastercard/AMEX/Discover）、PayPal、比特币和支付宝。

有个细节值得留意：RackNerd 默认不开自动扣款，续费账单需要手动支付。怕忘的话，可以在后台 Billing → Add Funds 预充一笔余额（比如年付 $35.99 就充 $36），账单生成后系统自动从余额里扣。

忘了续费也有缓冲余地：到期后有几天到一周的宽限期，期间服务暂停但数据不会立刻删除，付清账单即可恢复原机。有用户过期三天才付款，机器原样恢复、数据未丢。但宽限期不是无限期，拖到数据被清理就只能重购了——真到那一步，重新入手一台锁价款比什么都省事：👉 [重新开通 1GB 锁价套餐（$21.99/年）](https://my.racknerd.com/aff.php?aff=11397&pid=952)
